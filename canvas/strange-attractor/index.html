strange attractor

every path follows the same three equations, the Lorenz system, and nothing in them is random. the paths start a hair apart, and on average the gap between them grows about two and a half times with each unit of t, until they cover the whole shape. nothing is left to chance, and still a difference too small to see sends each path somewhere else: that is chaos.

the faint line behind them is one long path, which shows the shape they all move on.

  • tap or click anywhere to release every path from that point and watch them part again.
  • the presets show the same system with other settings: too little heat to stay chaotic, or so much that it finds order again.
  • in controls, ρ, σ and β change the rules while the paths move. the starting gap, the number of paths and the seed start them again.
  • the same seed and settings always give the same run. copy link, in controls, keeps them, so the link starts this run again from the beginning, anywhere. it can't keep what happened along the way, such as your taps. save image keeps the picture as it is now.

keys: space pause · r reset · n next seed, which starts the paths from a new place · 1–4 presets · c copy link · s save image · esc closes a panel
